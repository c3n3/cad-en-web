# 3D Prints

Tools for parts that will be 3D printed. The bag is hidden at first: open the Tool Ribbon Editor (the gear tab at the end of the ribbon) and drag **3D Prints** onto a tab.

| Tool | What it does |
|---|---|
| [Overhang](../tools/overhang.md) | Chamfer a feature's overhanging faces so it prints without supports. |
| [Infill](../tools/infill.md) | Leave cavities (spheres or channels) inside a body in its STL, to save material. |

Right-click any tool button and choose **Help** to see its page.
