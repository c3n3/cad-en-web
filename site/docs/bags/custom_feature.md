# Custom Feature

Make a custom feature: a set of sketches and features that other models can use as one tool. This bag is on the **Features** tab while a custom feature file (`.json.fcaden`, or `.py.fcaden`) is open.

| Tool | What it does |
|---|---|
| [Feature Definition](../tools/feature_definition.md) | Choose what the custom feature is made of, and name what it needs from the model using it. |

In a workspace, each file in the `.caden/custom_features` folder is a tool in its own bag on the Features tab, and each subfolder of `.caden/custom_features` is a bag of its own. See [Custom features](../guides/custom_features.md).

Right-click any tool button and choose **Help** to see its demonstration and page.
