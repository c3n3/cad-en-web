# Reference Geometry

Construction geometry other features are built from. These tools are on the **Features** tab of the ribbon.

| Tool | What it does |
|---|---|
| [Plane](../tools/plane.md) | A plane to sketch on or extrude to. |
| [Helix](../tools/helix.md) | A helix, e.g. a path for a thread. |
| [Vector](../tools/vector.md) | A direction (and length) other features can use. |

Right-click any tool button and choose **Help** to see its demonstration and page.
