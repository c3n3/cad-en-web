# Sketch Other

Measure, join, trim, write and annotate in a sketch. These tools are on the **Sketch** tab of the ribbon.

| Tool | What it does |
|---|---|
| [Measure](../tools/measure.md) | Read distances, angles and sizes off one or two items, without changing anything. |
| [Join Points](../tools/join_points.md) | Join the points of chosen items that lie within a tolerance of each other. |
| [Trim](../tools/trim.md) | Cut curves back to where they cross. |
| [Text](../tools/text.md) | Text as sketch geometry, along a line. |
| [Annotation](../tools/annotation.md) | A text note pinned to a point in the sketch. |

Right-click any tool button and choose **Help** to see its demonstration and page.
