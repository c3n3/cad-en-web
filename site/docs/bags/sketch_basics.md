# Sketch basics

Start a sketch, choose the tag new geometry goes on, select things and dimension them. These tools are on the **Sketch** tab of the ribbon.

| Tool | What it does |
|---|---|
| [New Sketch](../tools/new_sketch.md) | Start a sketch on a plane or a flat face. |
| [Tag selector](../tools/tag_selector.md) | The tag (and drawing style) new sketch geometry is put on. |
| [Select](../tools/select.md) | Pick, box-select and drag sketch and model items. |
| [Dimension](../tools/dimension.md) | Add a length, distance, angle, diameter or gap dimension. |

Right-click any tool button and choose **Help** to see its demonstration and page.
