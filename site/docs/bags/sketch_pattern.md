# Sketch pattern

Copy and repeat sketch geometry. These tools are on the **Sketch** tab of the ribbon.

| Tool | What it does |
|---|---|
| [Offset](../tools/offset.md) | Copies of curves a set distance away. |
| [Mirror](../tools/mirror.md) | Mirror geometry across a line. |
| [Rotate](../tools/rotate.md) | Rotate copies of geometry about a point. |
| [Project](../tools/project.md) | Bring edges and geometry from elsewhere into the sketch. |
| [Pattern](../tools/pattern.md) | Repeat geometry along one or two directions, or around a centre. |

Right-click any tool button and choose **Help** to see its demonstration and page.
