# 3D Pattern

Copy features and bodies. These tools are on the **Features** tab of the ribbon.

| Tool | What it does |
|---|---|
| [Rotate](../tools/rotate_feature.md) | Rotate copies of features or bodies about an axis. |
| [Mirror](../tools/mirror_feature.md) | Mirror features or bodies across a plane. |

Right-click any tool button and choose **Help** to see its demonstration and page.
