# Release 0.1.0 Alpha

The first release with built-in documentation.

## New
- **Documentation and help.** Every ribbon tool has a documentation page. Right-click a tool
  button and choose **Help** to open it, with a short demonstration of the tool.
- **Exact geometry engine.** Bodies are built as exact surfaces rather than triangle meshes, so
  curved faces stay round, fillets and chamfers follow true edges, and models export to STEP.
- **Join.** A new Features tool unites bodies that overlap or share a face into one body (the
  Intersect bag is now called **Combine**).
- **Assemblies.** An assembly file (`.acaden.py`) brings model files together: Insert Model,
  then Coincident, Parallel and Concentric constraints place them. Drag a model to move it within
  its constraints; the assembly updates when a model file changes. File › New Assembly, or the
  welcome page.
- **Concentric circle dimensions.** The Dimension tool measures the gap between two concentric
  circles or arcs.
- **Z up.** The view starts from the front-right-top corner with Z up, and the navigation cube's
  views keep Z up (Front looks from -Y, Top from +Z).

## Changed
- **Escape while drawing** removes the half-drawn shape's start point when nothing uses it.
- **Feature forms** open on their first empty pick box.
- **The "Resolving" window** stays over the CADen window instead of above every program.
