# Release notes

- AI API: Help > AI installs a skill folder and command-line tools so AI assistants can read, check and build CADen models
- Bug reports: Help > Bug Report... saves your session (what you did, the open models) to attach to a report
- Overhang tool (3D Prints bag, hidden by default): chamfers overhanging faces for 3D printing
- Tool Ribbon Editor: a bag can be on the ribbon more than once, the remove button works, arrows move bags, and the preview fills the pane and scrolls sideways
- Editing a feature rolls the model back to just before it and shows its sketch
