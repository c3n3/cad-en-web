# Release notes

- Master files: File > Create New starts a model, assembly or custom feature from a master file -- the built-in 3D Print master (print direction, print parameters, a support tag) or your own, installed with File > Install > Master File
- Vector parameters: `{0.1mm, 0.1mm, 0.1mm}`, read one value with `tol[0]`
- STL import: File > Import > STL, kept as `.zip.scaden` projects
- File names now end in the kind of file -- `part.json.caden`, `gear.py.tcaden`, `tools.zip.ccaden` -- so Windows
  can open them in CADen. Files with the older names (`part.caden.json`) still open; saving one renames it
- A workspace keeps everything of CADen's in one `.caden/` folder: custom features, templates, master files and
  settings (the older `.fcaden`, `.tcaden`, `.mcaden` and `.wcaden` folders are no longer read)
- Measure tool (M): distances, angles and sizes of sketch and body items
- Fillet and Chamfer on curved edges, and corners where filleted edges meet
- Mesh engine: faster, cleaner booleans; the engine is chosen per model
- Overhang works on custom features; Export STL can leave out bodies by tag
- Projecting a face keeps its exact curves: a round edge comes in as one circle, not segments
- The built-in gear templates and the 3D Print master file now ship in the downloads (the compiled builds
  were missing them)
- Faster loading of large gears; fixes to coincident constraints on rotated copies, picking the axes over sketch
  surfaces, radio buttons, plane tint and icons
