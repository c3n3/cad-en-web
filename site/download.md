# Download CADen

CADen is in **alpha**: early development, so expect rough edges and save your work often.
Choose your operating system; the download starts straight away.

<DownloadButtons />

Windows may warn that the app is from an unknown publisher (it isn't code-signed yet):
choose **More info**, then **Run anyway**.

The **portable zip** is the same program without an .exe: unzip it somewhere you can write to and
double-click `CADen.cmd`. The first run sets up its own Python (it needs 64-bit Python 3.12 or
[uv](https://docs.astral.sh/uv/), and internet access); its `README.txt` has the details.

New to CADen? Start with the [documentation](/docs/).
