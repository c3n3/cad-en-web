# Crates

Ready-made crates of custom features, functional features, templates and master files.
Install one from the **Crates** tab in CADen's side bar (it lists these, and offers an update when
a newer version is here), or download it and use **File > Install > Crate...**.

## Architecture

Version 1.0.0 -- [download](./crates/architecture.zip.ccaden){target="_self" download} (`architecture`)

Floor plans: draw the walls, windows and doors of a plan as tagged sketch surfaces; Floor Plan raises the walls and cuts the openings. A master file in feet with the wall, window and door tags and heights.
